# FMIS-LR

**Ferroptosis–Macrophage Integrated Ligand–Receptor Score**

A browser-local research workspace connecting nine-gene expression, molecular scoring, biochemical recurrence assessment and interactive reporting.

## Open the application

[FMIS-LR web application](https://zhuweiannn.github.io/fmis-lr/)

The application includes multilingual guidance, synthetic examples, batch processing, treatment exploration, parameter comparison and downloadable reports. User input is processed in the browser. This repository contains the deployed static website, not patient records or the private development repository.

For research use. Please read the application's usage and privacy information before processing data.
